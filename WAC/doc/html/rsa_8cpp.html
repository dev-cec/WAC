Detailed Description

RSA PKCS#1 v1.5 signature verification, in memory.

See rsa.h.

Numbers are held in 32-bit words, least significant first. Exponentiation by Montgomery multiplication (CIOS variant): it avoids any long division, the only tricky part of multi-precision arithmetic. The RSA modulus is odd, which Montgomery requires.
