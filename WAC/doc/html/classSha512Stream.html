Description détaillée

SHA-512, et SHA-384 qui en est la variante tronquée (autres constantes initiales, 48 octets rendus).

POURQUOI. Microsoft signe désormais avec la chaîne « Windows Production PCA 2023 », en sha384WithRSAEncryption : relevé sur le catalogue de Defender (wd_mpextdeps.cat) d'une installation Windows 11. Sans SHA-384, un fichier signé par cette chaîne ne peut pas être authentifié — et la migration de Microsoft vers cette chaîne en rendra la part croissante.
