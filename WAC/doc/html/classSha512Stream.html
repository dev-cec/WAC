Detailed Description

SHA-512, and SHA-384, its truncated variant (other initial constants, 48 bytes returned).

WHY. Microsoft now signs with the "Windows Production PCA 2023" chain, in sha384WithRSAEncryption: seen on Defender's catalog (wd_mpextdeps.cat) of a Windows 11 installation. Without SHA-384, a file signed by that chain cannot be authenticated — and Microsoft's move to that chain will make that share grow.
