◆ ENTRY_SIZE

const size_t UserAssist::ENTRY_SIZE = 72
static

Size of an entry of Windows 7 and later: session (4), run count (4), focus count (4), focus time (4), 10 usage ratios, last run FILETIME at offset 60, then 4 bytes. A value of another size is not a program entry: "UEME_CTLSESSION" holds session statistics, and read at the same offsets it gave a last run in 1691.
