◆ auditContexte()

Json auditContexte ( )

Contexte de la collecte : outil, machine examinée, fuseaux, opérateur.

Exposé parce que le manifeste de consigne doit porter EXACTEMENT le même contexte que le journal d'investigation. Le construire deux fois ouvrirait la possibilité que deux documents de la même collecte se contredisent — ce qui suffirait à discréditer les deux.

Renvoie
un objet JSON { Tool, Host, Operator }
