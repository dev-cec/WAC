◆ reference

MFTInformation Filename::reference

Référence $MFT du fichier chargé, lue dans le tableau des métriques.

Elle identifie le fichier sur le volume INDÉPENDAMMENT de son nom : un exécutable renommé ou supprimé depuis se retrouve par son numéro d'enregistrement, ce que le chemin seul ne permet pas. Nulle quand le tableau des métriques ne la donne pas ou que l'appariement avec le nom n'est pas sûr — mieux vaut pas de référence qu'une référence attribuée au mauvais fichier.
