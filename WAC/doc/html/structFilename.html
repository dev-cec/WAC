◆ reference

MFTInformation Filename::reference

$MFT reference of the loaded file, read from the metrics array.

It identifies the file on the volume INDEPENDENTLY of its name: an executable renamed or deleted since is found again by its record number, which the path alone does not allow. Null when the metrics array does not give it, or when the match with the name is not certain — no reference is better than a reference attributed to the wrong file.
