Detailed Description

The FileAttributesFlags structure defines bits that specify the file attributes of the link target, if the target is a file system item. The file attributes can be used if the link target is not available, or if accessing the target would be inefficient. The target's attributes may not be in sync with this value. Documentation: https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-shllink/378f485c-0be9-47a4-a261-7df467c3c9c6
