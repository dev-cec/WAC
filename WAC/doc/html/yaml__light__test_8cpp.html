Detailed Description

Checks the strict reading of wac.yml: what it accepts, what it refuses and at which line, and that damaged texts never break it.

WHY THIS TEST. A configuration misread changes what a collection takes, and nothing shows it. Each construct a configuration does not use must be refused, with the line at fault; the ones it uses must be read exactly. Then a valid configuration altered at random (fixed seed) must never make the reading crash or leave its bounds — built with AddressSanitizer and UBSan, libyaml included.

Usage: yaml_light_test Native build (Linux), libyaml's sources beside: L=../third_party/libyaml-0.2.5 gcc -c -g -fsanitize=address,undefined -DYAML_DECLARE_STATIC -DYAML_VERSION_MAJOR=0 -DYAML_VERSION_MINOR=2 \ -DYAML_VERSION_PATCH=5 '-DYAML_VERSION_STRING="0.2.5"' -I$L/include $L/src/{api,reader,scanner,parser}.c g++ -std=c++17 -g -fsanitize=address,undefined -DYAML_DECLARE_STATIC -I$L/include -I. \ yaml_light.cpp yaml_light_test.cpp api.o reader.o scanner.o parser.o -o yaml_light_test
