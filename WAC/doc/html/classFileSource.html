Detailed Description

Where the files a conversion needs are read from: the examined volume itself (RawReader, collection on the machine), or the exhibit store of a collection made earlier (ExhibitReader, –convert on an analysis workstation). The consumers — cited binaries, signature catalogs — read through this interface and do not know which one serves them.
