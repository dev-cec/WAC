Detailed Description

Header of an OLE / CFB (Compound File Binary) container.

These fields are navigation coordinates inside the container (sector sizes, allocation tables), NOT investigation data: the usable traces of an automatic jump list are in the DestList stream and in the shell items, which oleParser reaches thanks to this header.

The files parsed come from a suspect machine: they are not trusted. Every value that serves to compute an offset is therefore validated here, before use.
