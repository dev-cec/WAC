Detailed Description

THE LISTS OF VULNERABLE DRIVERS, at the collection: a binary whose signature holds may still be a driver an attacker brings to open the kernel (BYOVD) — signed, genuine, and vulnerable. Such a binary is not cleared.

A binary is listed when one of its fingerprints — Authenticode, or of the file — is in Microsoft's blocklist or LOLDrivers (the Authenticode digest of WAC is LOLDrivers' Authentihash: measured equal on four samples), or when a denied signer of Microsoft's blocklist matches: its authority in the chain, and every narrowing it gives. A file rule is judged on the version resource, as Windows judges it: a binary that has none does not match it (its fingerprints still count — and the resource cannot be taken out without breaking the signature). A binary NOT READ for it — too large to be held in memory — matches it: what cannot be told apart is not cleared.

Built once, shared by the analysis threads (read only).
