Detailed Description

OpenSaveMRU: the files the user opened or saved through a dialog box.

WHAT IT SHOWS. Every Open and Save dialog leaves the chosen file in a per-extension list. That documents the handling of a document whatever the application, including files that have since been deleted, and files on a removable device or a network share which left no other trace on the disk. The entries are ordered by MRUListEx, most recent first.

WHERE IT IS READ. In each NTUSER.DAT, under Software\Microsoft\Windows\CurrentVersion\Explorer\ComDlg32: OpenSavePidlMRU (shell items, the current form) and OpenSaveMRU (plain paths, older systems).

Each entry is a PIDL — a chain of shell items parsed by idList.h — and not a text path: it carries the target's name, size and timestamps AS THEY WERE when the dialog was used, which the file itself no longer holds.
