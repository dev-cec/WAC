Detailed Description

Logon sessions open on the machine while the collection runs.

WHAT IT SHOWS. Who is logged on AT THIS INSTANT, how they authenticated (password, certificate, network, service), from which domain, and since when. It is volatile: the session list disappears with the power, so it is read on the live machine, unlike the artefacts collected from the disk.

It also documents the collection itself — the operator's own session is among them, which shows what was open on the examined machine at the time.

WHERE IT IS READ. Through LsaEnumerateLogonSessions and LsaGetLogonSessionData, the only source for this information: it exists nowhere on the disk.
