Description détaillée

Empreinte attendue d'une opération : la trace qu'elle laisse sur le système examiné. Sert à renseigner le champ Footprint du journal.

Les valeurs sont volontairement descriptives plutôt que codées : elles sont destinées à être lues par un analyste humain dans le rapport.
