Detailed Description

Parsing of MESSAGETABLE and WEVT_TEMPLATE, and substitution of the marks.

See wevt.h for the chain to walk back and for the formats.

Structures, as libyal's reference implementation (libfwevt) describes them:

manifest "CRIM" (4), size (4), major (2), minor (2), number of providers (4) = 16 entry GUID (16), offset of the data (4) = 20 provider "WEVT" (4), size (4), message identifier (4), number of descriptors (4), number of unknowns (4) = 20 then an offset of 4 bytes per descriptor events "EVNT" (4), size (4), number of events (4), unknown (4) = 16 event identifier (2), version (1), channel (1), level (1), opcode (1), task (2), keywords (8), MESSAGE IDENTIFIER (4), then six fields of 4 = 44

An event's value as Windows shows it in the message, from its template item. Measured on the test VM against EvtFormatMessage (B-023), item types read in the providers' manifests:

  • a value map's label: "État : 2" -> "État : Disconnected" (Kernel-Power); a bitmap's labels of the flags set, joined by commas without space ("67108880" -> "BackgroundTaskOption,LowPriorityRequest", AppX); a bitmap's zero stays the number (Kernel-Boot 153);
  • a hexadecimal input type (win:HexInt32, win:HexInt64), or a hexadecimal output type of an integer, and win:ErrorCode, as 0x and upper-case digits: "0x3e7" -> "0x3E7", "2147746053" -> "0x80040105". A pointer keeps the log's form ("0x1b3c");
  • an error code by its text: win:Win32Error and win:HResult from the system's table ("87" -> "Paramètre incorrect."), a Win32 HRESULT (0x8007xxxx) by its Win32 code first, an unknown HRESULT "Unknown HResult Error code: 0x…" without its 0x10000000 bit, as Windows writes it; win:NTSTATUS from ntdll's ("0" -> "STATUS_SUCCESS");
  • binary data as xs:hexBinary: "0x" before its digits; as win:SocketAddress, an IPv4 address and its port ("127.0.0.1:58241").
  • a win:Double, 15 significant digits ("17.4690293241336"), where the log's XML gives the shortest exact form ("17.469029324133604"): Vista and Windows 11 render a record of Vista's ReadyBoost alike. A value that is no number, absent from its map or from the tables, stays as it is.

Replaces the %1 %2 … marks by the event's data.

Windows writes its templates with positional marks, and sometimes with layout escape sequences (n, t, %%). A mark without matching data is left as it is: erasing it would suggest a complete sentence whereas a value is missing.

Parameters
messageTemplatetext taken from the message table
valuesdata of the event, in order (%1 is the first)
Returns
the sentence, or an empty string if the template is empty
