Detailed Description

The texts WAC shows the operator, in French and in English.

WHAT IS TRANSLATED. The console only: steps, headings, help, refusals of the command line and of wac.yml. The JSON files, WAC.log and the investigation log stay in English whatever the language: they are evidence read by tools, and one collection must give the same files whoever ran it.

WHY AN ENUMERATION. Every text is named by a value of Text, and the table of translations.cpp holds, for each one and in the same order, its French and its English wording: a text added without its translation, or a table out of order, does not compile. Looking the text up by its English wording would fall back on English without a word.

The language is French by default; wac.yml (language:) or the command line (–language=) changes it.
