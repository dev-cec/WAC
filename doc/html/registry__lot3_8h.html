Detailed Description

Registry artefacts of the third lot (B-031): the keys RECmd's Kroll batch reads and WAC did not.

Each is read in the copied hives and shares the structure of the second lot (registry_lot2.h): one struct per element with toJson(), one class with getData(), toJson(), clear().

WHAT THEY PROVE.

  • Installed programs (Uninstall): what was installed, by whom (machine or user), when, where — a remote access tool, a miner — and what was removed since leaves the key's last write.
  • Defender configuration: the exclusions (paths, extensions, processes, addresses) an intruder adds so that their tools are not scanned, and the values that switch protection off — set in Defender's own settings or by a policy.
  • Explorer's RecentDocs: the files each user opened, by extension, most recent first — the names survive the files and the shortcuts of Recent.
  • MountPoints2: the volumes and network shares each user's Explorer saw (a USB key, \\server\share), the last time it did, and the commands an entry may carry (Shell\AutoRun\command: an old persistence).
  • Known networks (NetworkList): every network the machine joined — its name, its kind, its gateway's hardware address, when it was first and last connected: where the machine has been.
  • Program usage: what each user launched or used — FeatureUsage counts, JumplistData's last use, the Program Compatibility Assistant's store of programs run, compatibility layers, RADAR's diagnosed programs, the taskbar's pinned items (Taskband, each a whole shortcut), and the programs chosen to open each file type (FileExts).
  • Devices: the USB and SCSI devices the machine enumerated (Enum\USB, Enum\SCSI) with their install, first install, last arrival and last removal dates; the portable devices (a phone, a camera); the volume labels Windows Search cached per drive letter; the disk, volume and portable-device interfaces of DeviceClasses.
  • Network shares: the folders the machine shares (LanmanServer\Shares), a way in or out for data; the administrative ones (C$, ADMIN$) are not stored there.
  • Network configuration, read offline: each adapter (description, driver, a forced hardware address), its last IPv4 and IPv6 settings and DHCP lease — what the live state no longer shows once the machine is unplugged or the lease gone.
  • Event log configuration: each channel's state (enabled or not, size, retention, access), the classic logs' and the boot ETW sessions' — an intruder who disables a channel, shrinks a log or stops a session leaves it there.
