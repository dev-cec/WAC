Detailed Description

Checks decodeNtfsRuns: data runs decoded exactly, a forged list refused whole, and nothing read outside the attribute; and the other bounds the raw reader takes from a record — a resident attribute's value, the compression unit, the index block size.

WHY THIS TEST. The data runs say where a file's clusters lie. Read from a deleted record (B-036), they are what an intruder or a damaged disk left: a header announcing fields of up to 15 bytes shifted the bytes past the width of the integer, and a run of length zero or before the volume's start was taken as it came. The lists here are built by hand, so that the expected runs are known; random lists are then placed against a PAGE_NOACCESS page (guard_page.h), both sides, and compared with an independent decoder.

Usage: ntfs_runs_test Built by build-windows.sh --test; runs under Wine or on Windows.
