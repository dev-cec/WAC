◆ _debug

bool AppliConf::_debug = false

Diagnostic mode (–debug). Turns on the detailed trace of the NTFS parser (path resolution, index blocks, data runs) on STDERR. Separate from –loglevel: that one logs the COLLECTION (which artefacts, which values), whereas –debug lights up the LOW-LEVEL READING of the volume. Mixing the two drowned the console in ordinary use, while that trace is precisely what allowed the split $INDEX_ALLOCATION defect to be located.

◆ systemDrive

std::wstring AppliConf::systemDrive = L"C:"

System drive of the examined machine, with its colon ("C:").

Read at run time rather than hard-coded: Windows is not always installed on C:. The value serves both the raw extraction (volume letter) and the restitution of the artefacts' original paths.

◆ threads

–threads=N: threads analysing the executables of –collect –binary (PE, Authenticode, catalogs, fingerprints); 0 = the processor's threads minus one, the reading of the volume keeping its own.
