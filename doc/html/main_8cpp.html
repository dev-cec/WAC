◆ clearConsole()

void clearConsole ( HANDLE  console)

Clears the console WAC writes to, through the console API. It used to be system("cls"): a cmd.exe started by WAC on the examined machine — a process creation, and the Prefetch of CMD.EXE updated — for a cosmetic effect (measured, backlog B-027). Without it, WAC imports no function that starts a process. When the output is not a console (a file, a pipe), the calls fail and nothing is done.

Parameters
consolethe console's output handle

◆ convertNtfsMetadata()

void convertNtfsMetadata ( )

The $MFT, the change journal and the Zone.Identifier streams of every fixed NTFS volume. Each volume's $MFT is loaded once for the three: the journal names its files through it, and the streams are in its records. Every volume goes into the same mft.json and usn_journal.json, each record carrying its volume — record numbers only mean something within theirs. An artefact is "not collected" only if no volume gave it.

Loads the trust set of the key, which clears third-party signatures (–binary), and records what it is — or that there is none, and why: the third-party binaries are then all collected. Loaded before the first executable is read, so that one set judges them all.

◆ openCurrentControlSet()

HRESULT openCurrentControlSet ( )

Opens SYSTEM's CurrentControlSet: the ControlSetNNN that Select\Current names, in conf.CurrentControlSet. Needed by the conversion and by –collect alike: without it, a collection for a later conversion took the event messages' satellites in en-US instead of the machine's language, and found no classic event source (B-023).

Returns

◆ prepareConversion()

HRESULT prepareConversion ( )

–convert: checks the collection before anything is read from it — the seal, then every exhibit's fingerprint —, then rebuilds the working copy from the exhibit store, as the collection made it: copies verified against the manifest, hives repaired. The working directory is derived data: an earlier one, possibly altered by an analysis, is deleted rather than trusted.

Returns
ERROR_SUCCESS, or the reason of the refusal
