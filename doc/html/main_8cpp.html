◆ applyArtefactCatalogue()

void applyArtefactCatalogue ( )

THE GUARD BEFORE ANY COLLECTION (backlog B-039). Reads the version of the examined Windows in its SOFTWARE hive, just opened, and applies the table of the artefacts (artefact_catalogue.h): an artefact asked for that this version does not have is switched off — neither launched nor counted as a failure — and remembered, so that its file says "absent from this version". One whose form on this version WAC has no decoder for (undecodedOn) is collected as usual, and at the conversion declared "unsupported format" instead of being read with another version's decoder. A version newer than the table is treated as the last one known, and said so; an unreadable one holds nothing back. Announced on the console and recorded in the investigation log.

◆ clearConsole()

void clearConsole ( HANDLE  console)

Clears the console WAC writes to, through the console API. It used to be system("cls"): a cmd.exe started by WAC on the examined machine — a process creation, and the Prefetch of CMD.EXE updated — for a cosmetic effect (measured, backlog B-027). Without it, WAC imports no function that starts a process. When the output is not a console (a file, a pipe), the calls fail and nothing is done.

◆ convertNtfsMetadata()

void convertNtfsMetadata ( )

The $MFT, the change journal and the Zone.Identifier streams of every fixed NTFS volume. Each volume's $MFT is loaded once for the three: the journal names its files through it, and the streams are in its records. Every volume goes into the same mft.json and usn_journal.json, each record carrying its volume — record numbers only mean something within theirs. An artefact is "not collected" only if no volume gave it.

◆ convertShadowCopies()

void convertShadowCopies ( )

What the shadow copies keep and the volume no longer holds (B-014).

WHY NOT EVERYTHING. A copy converted whole repeats, nearly identical, the thousands of entries of the volume's conversion, once per copy: huge, and what matters drowned. What a copy brings is what was there THEN and is gone NOW — what an intruder erases. Hence two files:

  • shadow_copy_events.json: the events of a copy's logs that the volume's logs no longer hold (a cleared Security log, records overwritten by rotation), each once, with the newest copy that kept it;
  • shadow_copy_registry.json: the entries of the registry artefacts converted from a copy's hives that the volume's conversion does not give (a Run value, a service, an account deleted since; a ShimCache, Amcache or BAM entry of a tool deleted since), compared on their identity (entryIdentity), each once, with its artefact and the newest copy that kept it. The copies are taken newest first. A copy's tree, in the working directory, was completed with the files it shares with a newer version before the hives were repaired (shadowCopyTreesToWorking). The registry artefacts are converted into a folder apart, compared, and that folder removed.

The copies of the system volume only: they hold the system's hives and logs.

◆ entryIdentity()

std::wstring entryIdentity ( const Json &  entry)

What identifies a registry entry across time: the entry without its fields that move with use alone — dates, counters, positions in a list (UserAssist's FocusCount, an account's LogonCount, a key's KeyLastWrite, an MRU position). Compared with them, every entry a user touched since the copy came out "gone" (measured on Windows 7: most of the list); without them, what is listed is gone indeed, or changed in what it says — a Run value pointing elsewhere, a member taken out of a group.

◆ shadowCopyTreesToWorking()

size_t shadowCopyTreesToWorking ( )

Completes each shadow copy's tree in the working directory with the files it shares with a newer version — not copied twice at collection, the manifest pointing them to that version's exhibit (SharedExhibit).

WHY HERE, before the hives are repaired. A shared file is the RAW content of the other version: copied after the repair, a copy's SOFTWARE took the volume's base replayed with the volume's logs, and the copy's own logs, stored apart, were never replayed — a Run value the copy kept was lost (measured on Windows 11). Copied here, from the working copy just made, each copy's hive is repaired with its own logs like any other.

Returns
the number of files put in the copies' trees
