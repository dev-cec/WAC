Detailed Description

Shortcuts outside the Recent folder: Start menu, desktop, Quick Launch and pinned task bar.

WHAT THE ARTEFACT PROVES. Recent (recentdocs.json) holds the shortcuts Windows makes when a document is opened; these are the ones a person or an installer PUT somewhere to be clicked: the Start menu of all users and of each profile, the desktop of each profile and the public one, Quick Launch and what is pinned to the task bar. An installed program leaves its shortcut there, and it outlives the program's removal; an intruder plants one there with a command line in its arguments, or retargets an existing one at their own binary (the icon stays the same). The target, its arguments, the volume and machine it was on are decoded as in recentdocs.json.

WHAT IS LEFT OUT. The Start menu's Startup folder: startup_folders.json takes it whole, every file and not only shortcuts. Taken here too, its shortcuts would be extracted and listed twice.

These folders were the first gap B-015 found between WAC and KAPE's KapeTriage target (backlog B-032).
