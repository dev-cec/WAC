Detailed Description

Amcache: the inventory Windows keeps of the applications, binaries, drivers, devices and shortcuts the machine has known.

WHAT IT SHOWS. Windows\AppCompat\Programs\Amcache.hve is a hive of its own, whose Root\Inventory* keys each hold one table: InventoryApplication (the installed products), InventoryApplicationFile (the executables, with their SHA-1, size and PE link date), InventoryDriverBinary, InventoryDevicePnp, InventoryApplicationShortcut… An entry proves the object was PRESENT and inventoried, not that it ran; it survives the object's deletion, and the SHA-1 identifies a binary long gone.

WHY EVERY VALUE. Only four to six values of two tables were read: no SHA-1, no size, no driver, no device (B-015, against AmcacheParser, which gives them). Each table is now read whole — every value of every entry, typed as the hive stores it, with the key's last write time — so that a value a later Windows adds is not lost either. Values are converted only where the conversion was checked:

  • FileId of an executable and DriverId of a driver ("0000" + 40 hexadecimal digits) give AmcacheSha1; for a file larger than 30 MiB, Amcache hashed only its first 31,457,280 bytes, which AmcacheSha1CoversBytes says;
  • LinkDate, InventoryApplication's InstallDate and a driver's DriverLastWriteTime, text dates, are UTC (measured against the PE header, the folder's creation and the driver file's own date);
  • DriverTimeStamp, the driver's PE TimeDateStamp, is a Unix time;
  • LowerCaseLongPath is published as LongPath, its name since the start. The other text dates are given as written: a device's InstallDate holds only the day, a driver package's Date too; their time zone is not known.

OUTPUT. InventoryApplication in amcache_applications.json, InventoryApplicationFile in amcache_application_files.json (their names since the start), every other table in amcache_inventory.json, each entry with its Table.

WINDOWS 7: RecentFileCache.bcf. Before Amcache.hve (and next to it once KB2952664 brought it to Windows 7), Windows lists in Windows\AppCompat\Programs\RecentFileCache.bcf the executables run since the last pass of its ProgramDataUpdater task: their paths only, no date. A header of 20 bytes, its first 8 a signature (FE FF EE FF 11 22 00 00), the others not known; then each path as a count of characters on 32 bits, the characters in UTF-16 and a null. Measured on the Windows 7 VM. Each path goes to amcache_application_files.json with Table "RecentFileCache".
