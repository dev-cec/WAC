Detailed Description

A value whose entries are a table of fixed size, each pointing at its path, stored after the table: Windows 7, Vista and Server 2003. An entry starts the same way in all three — path length (2), its room (2), then the path's offset (4 bytes in 32 bits; 8 after 4 reserved bytes in 64 bits), then the file's last modification —; the header and what follows the date differ.
