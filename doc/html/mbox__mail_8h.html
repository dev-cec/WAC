Detailed Description

Thunderbird's mailboxes: mbox files and the MIME messages in them.

THE FORMAT. Thunderbird keeps each mail folder as one mbox file, without extension, in the profile's Mail\\<account> or ImapMail\\<server> folder (subfolders in a <name>.sbd folder beside it, the index in <name>.msf, not read): the messages one after the other, each preceded by a "From " line at the start of a line after an empty one. Each message is an Internet message (RFC 5322) in MIME (RFC 2045 to 2049): headers — folded lines, encoded words (RFC 2047) —, then a body, possibly multipart, its parts encoded in base64 or quoted-printable, in a character set of their own; a part with a file name (RFC 2231 included) is an attachment.

HOSTILE INPUT. A message is whatever its sender wrote: every boundary is looked for within the message, the nesting of multiparts is bounded, a message larger than MBOX_MESSAGE_MAX is skipped and counted, never read past. Checked against Python's own mailbox and email modules on the messages Thunderbird wrote in the test VM.
