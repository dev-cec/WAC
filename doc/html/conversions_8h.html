Detailed Description

The general conversions of bytes, in one place and self-contained.

WHY A HEADER OF ITS OWN. These conversions were scattered: toHexadecimal in sha.h, which any module wanting to print bytes had to include, and one little-endian reader per module. They gather here (backlog B-030), header-only and depending on nothing of WAC, so that tools.h and the harnesses that link without tools.cpp (raw_hive_test: sha.cpp) share the same code.

◆ to_hex()

template<typename T >

int  minDigits = 2,
HexLetters  letters = HexLetters::Lower,
bool  prefixed = false

Writes an integer in lower-case hexadecimal, on the WIDTH OF ITS TYPE.

A template rather than one long long signature: every value used to be widened to 64 bits first, so a negative 32-bit value — an HRESULT such as 0x80070005 — came out as "ffffffff80070005". The value is now read as the unsigned type of the same width. A char is written as a number, never as a character.

Parameters
valuethe integer
minDigitsminimum number of digits, left-padded with zeros (2 by default; 1 for no padding, e.g. the stream names of a jump list)
letterslower case (the default) or upper case
prefixed"0x" before the digits
Returns
the digits, "0x" first if prefixed
