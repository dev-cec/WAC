◆ loadSuspectTimeZoneHistory()

HRESULT loadSuspectTimeZoneHistory ( )

Reads the offsets the System log holds (its working copy, archives and a moved log included: workingEventLogs), and TZUtil's log, and fills conf.timeZone.history. To be called after loadSuspectTimeZone, which clears it, and before any local time is converted.

Returns
ERROR_SUCCESS; ERROR_FILE_NOT_FOUND (as HRESULT) when the collection holds no System log — the rules alone then apply; S_FALSE when records of it could not be read

◆ zoneInForceOf()

bool zoneInForceOf ( const XmlNode & event,
long & standardBias,
std::wstring & standardName )

The zone an EventLog 6013 (Server 2008 R2), 6005 or 6006 (Server 2003) says in force: its last datum, "<standard offset> <standard name>" ("-60 Romance Standard Time", "-60 Paris, Madrid" in French) — the Binary after it is not a datum (measured on both, 2026-11-10).

Parameters
eventthe event, parsed
standardBiasreceives the standard offset, in minutes: UTC = local + bias
standardNamereceives the standard name
Returns
false for another event, or a datum not of that form
