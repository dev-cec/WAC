Detailed Description

LEVEL 2 — THE SLACK OF THE DIRECTORY INDEXES. A directory lists its files in index blocks (INDX) of $I30; an entry removed — the file deleted, moved, renamed — leaves its bytes beyond the node's used size until the node grows again, and a block the directory released keeps all of its former entries. Each entry is the file's $FILE_NAME: its name, its record, its four dates, its size. Most of the slack repeats live entries the tree moved (Windows 8: 52,789 entries in the slack, 41 names absent from every live index — B-036): only a name that no directory holds any more is published, and no content — the name, when the file existed, and which record it was.

An entry found in the slack of an index block.
