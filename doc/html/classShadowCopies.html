◆ refresh()

bool ShadowCopies::refresh ( std::wstring &  diagnostic)

Reads the catalog again and, if the copies are the same, the most recent store's block list — the only one Windows adds to while the volume is written; any other change of the catalog (a copy created or deleted) reads everything again.

WHY. On a running machine, a block written after the block lists were read has had its earlier content copied to the most recent store by a descriptor not known yet: read from the volume, it would give the copy a block it never held. Refreshed before each file, the lists know every block copied so far.

Parameters
diagnosticreceives why the reading stopped, if it did
Returns
false if the catalog or a store could not be read
