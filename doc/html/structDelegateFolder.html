Detailed Description

Delegate folder.

Recognised by the delegation GUID written 32 bytes before the end ({5E591A74-DF96-48D3-8D67-1733BCEE28BA}); the GUID of the delegating class occupies the last 16 bytes. At offset 4, the size of the delegated data (2 bytes); from offset 6, those data, which continue an item of the class the class byte gives (a drive root folder, a search folder…). They are decoded as such, into innerItem.

It was not recognised at all: the whole item — hence the shell item it holds, with its path, its dates and its property stores — was reduced to an "UNKNOWN" object. It was the missing type that cost the most, because it is common in the shellbags and it hides a decodable item.
