Detailed Description

An offset the examined machine wrote in its System log, at an instant: Kernel-General 22 (NewBias, on every change of offset — a time zone set, a daylight saving transition — while the machine runs), 24 (CurrentBias, at each boot and each refresh) or 1 (TimeZoneBias, each time the clock is set). Measured on Windows 11 and Server 2025, 2026-11-09: a time zone set by tzutil writes 22, 24 and 1 at the same instant.
