Detailed Description

The event logs the examined machine keeps outside their default folder (backlog B-053).

WHY. A log's file is a setting: the File value of its channel (SOFTWARE …\WINEVT\Channels\<channel>, what wevtutil sl /lfn writes) or of its classic log (SYSTEM …\Services\EventLog\<log>). Moved — by an administrator for room, or by an intruder for a log nobody looks at —, a log WAC looked for in winevt\Logs only was neither collected nor converted, and its absence read as "no events". Sysmon's own log, the best source of detection where it runs, is one a hardened configuration often moves.

The values are read in the examined machine's hives, expanded as Windows does (SystemRoot%, normalizeFilePath): the collection takes these files raw, the conversion reads them with the others.
