std::vector< std::wstring > firewallLogFiles ( )

The firewall's logs the examined registry names, and the defaults: each once, case ignored, absolute; the rotated .old of each is not listed. Needs conf.CurrentControlSet and conf.Software (either missing: its settings are not read; the defaults stay).
