Detailed Description

Analysis of a PE file fed as a stream: Authenticode digests and certificate table, computed while reading, without reading the file again.

The Authenticode digest covers the whole file EXCEPT the optional header's CheckSum field, the "certificate table" entry of the data directory, and the certificate table itself.
