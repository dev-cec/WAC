Detailed Description

Matching a name with a pattern where * stands for any run of characters and ? for one: the filter of the raw folder reading (raw_hive.cpp), of the applications' traces table (application_traces.cpp) and of the web servers' Include masks (web_installations.cpp) — one function, where there were two.

A header of its own, inline and portable: the NTFS reader and the table both use it without depending on each other, and the table's test builds natively as well as under MinGW.

Compares a file name with a filter, as the raw folder reading keeps a file and the conversion finds it again: an entry starting with "." is an extension, one holding * or ? a pattern ("connections*.txt"), any other a whole name ("Thumbs.db"). Extensions and whole names ignore case as Windows does (towlower), patterns in ASCII (wildcardMatch).

bool wildcardMatch ( const std::wstring & pattern,

inline

Compares a name with a pattern, case-insensitively (ASCII). * stands for any run of characters, none included; ? for exactly one; every other character for itself. Iterative: a forged name of any length costs at most pattern × name, never a deep recursion.
