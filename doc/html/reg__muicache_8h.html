Detailed Description

MUICache: executables run through the shell, and their display name.

WHAT IT SHOWS. When the shell displays an application's name, it caches the name read from the binary's resources, keyed by the binary's path. An entry therefore means the executable was PRESENT and shown by the shell — it is a weaker execution indicator than BAM or Prefetch, but it survives the deletion of the binary, and it carries the name the program gave itself, which a renamed executable contradicts.

WHERE IT IS READ. In each user's UsrClass.dat (Local Settings\Software\Microsoft\Windows\Shell\MuiCache), and on Windows XP and Server 2003 in NTUSER.DAT (Software\Microsoft\Windows\ShellNoRoam\MUICache, the same values, with a binary LangID beside them), so the entries are attributed to the user whose hive holds them. The keys carry no timestamp of their own: only the key's last write time bounds the cache.
