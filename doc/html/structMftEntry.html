Detailed Description

One record of the $MFT: a file or a directory, present or deleted.

◆ nameRank

int MftEntry::nameRank = 3

Preference of name's namespace (namePreference): 0 long name, 1 POSIX, 2 the 8.3 alias, 3 none. A record with many names has its long one in an extension record and only its alias here: the better name wins, wherever it lies.

◆ zoneIdentifier

bool MftEntry::zoneIdentifier = false

the record has a Zone.Identifier stream

The Zone.Identifier stream ("Mark of the Web", written by browsers and mail clients on what they download). Almost always resident — held in the record itself —, so the copy of the $MFT carries its content, with no further read of the examined machine.
