Detailed Description

Programs started automatically at logon: Run and RunOnce keys.

WHAT IT SHOWS. These four keys are the first place a program installs itself to survive a reboot, and the most-used persistence of commodity malware. Run starts its values at every logon; RunOnce starts them once, then Windows deletes the value — so a RunOnce value still present was written since the last logon, or never ran.

WHERE IT IS READ. Machine-wide in SOFTWARE (Microsoft\Windows\CurrentVersion\Run and RunOnce), and per user in each NTUSER.DAT (Software\Microsoft\Windows\CurrentVersion\Run, RunOnce), which tells whose logon starts the program, and in the DEFAULT hive, the profile of the system account.

The key's last write time dates the last change to the whole key, not to one value: it bounds when the entry appeared, it does not date it.

ALSO READ (B-031, against RECmd's Kroll batch): the 32-bit programs' Run and RunOnce (WOW6432Node, machine-wide); Explorer\StartupApproved\Run, Run32 and StartupFolder, where Windows records an entry's state as the user set it in Task Manager or Settings — a status code (the first four bytes, as stored: their meaning is not measured, so not interpreted) and the instant of the change; RunNotification, one StartupTNoti<name> per startup entry Windows noticed, its state as stored. A StartupApproved or RunNotification name without a Run value is an entry since removed.
