Detailed Description

The VARIANT type of each property of the Windows Search index, by its canonical name: what the ESE index (Windows.edb) does not say.

SOURCE. The table SystemIndex_1_PropertyStore_Metadata of the Windows 11 test VM (Windows.db, 614 properties: Name, VariantType), where Windows declares each one; the codes are those of [MS-OLEPS] (31 VT_LPWSTR, 64 VT_FILETIME, 21 VT_UI8…). The property system gives a property the same type on every Windows; a property this table does not hold is given as its bytes. Generated, not written by hand: regenerate it from that table, never edit one line.
