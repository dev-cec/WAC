Detailed Description

Microsoft Defender's detection history and quarantine: \ProgramData\Microsoft\Windows Defender\Scans\History\Service\DetectionHistory and …\Windows Defender\Quarantine.

WHAT THEY PROVE. One DetectionHistory file per detection: the threat, the file or key it was found in, the process that touched it, the account, and when. It outlives the event log: a detection whose events were cleared is still there. The quarantine keeps what Defender removed — the file's original path, its dates and attributes, and its content.

THE DETECTIONHISTORY FORMAT, undocumented, established on Defender 4.18.26080 (Magic.Version 1.2) against MSFT_MpThreatDetection on two detections that differ: a sequence of fields, each "size (4 bytes), type (4 bytes), value", aligned on 8 bytes. Types 0x06 a 32-bit number, 0x08 a 64-bit one, 0x0A a FILETIME, 0x15 a UTF-16 string, 0x1E a GUID, 0x28 a bag of NAMED properties (ThreatTrackingSha1, …ThreatTrackingStartTime…). Only the fields whose position the reference confirmed are named; every other one is given as read — offset, type, value — without a meaning made up. Two fields that both follow DetectionSourceTypeID, two dates that both equal RemediationTime, stay unnamed for that reason. Defender of Windows 8.1 writes the same fields without any Magic.Version marker — the threat's name comes right after the detection's GUID, a resource is its type and path alone —, established the same way against MSFT_MpThreat and MSFT_MpThreatDetection on two detections.

THE QUARANTINE, established the same way against a file of known dates. EntriesGUID} describes a quarantine: three parts, each encrypted with RC4 under a fixed key found in mpengine.dll (published: ERNW, "quarantine-formats"; N. Knežević, "defender-dump"). ResourceData\xx<SHA-1> holds the removed file, encrypted the same way. The exhibits are copied AS THEY ARE, encrypted: nothing malicious is written in clear, on the collection medium or on the analysis workstation (user decision 2026-09-30). The content is decrypted in memory only, for its size and fingerprints.
