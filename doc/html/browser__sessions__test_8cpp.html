Detailed Description

Checks the decoding of the browsers' sessions: LZ4 blocks against an independent compressor, SNSS files built field by field, and both damaged at random.

WHY THIS TEST. A session file says which pages were open, and when: a field read one place off gives another URL or another instant, in valid JSON. The LZ4 vectors are made by Python's lz4 module (lz4.block.compress, store_size=False), an implementation independent of WAC's: each must decompress byte for byte. The SNSS files are written here as Chromium's base::Pickle lays them out (32-bit sizes, fields aligned to 32 bits): a navigation replaced by a later one, an older navigation without the fields after its title, a closed tab and its instant, a truncated command. Then every input, damaged and truncated at random (fixed seed), must never make the decoders read or write out of bounds — built with AddressSanitizer and UBSan.

Usage: browser_sessions_test [<original> <lz4-block>] ... Vectors: python3 -c "import lz4.block,sys; d=open(sys.argv[1],'rb').read(); open(sys.argv[2],'wb').write(lz4.block.compress(d, store_size=False))" in out Native build (Linux): g++ -std=c++17 -g -fsanitize=address,undefined -I. browser_sessions.cpp browser_sessions_test.cpp -o browser_sessions_test
