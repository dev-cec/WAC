Detailed Description

The Intune Management Extension's logs (backlog B-052).

WHAT THE ARTEFACT PROVES. On a machine managed by Microsoft Intune, the management extension writes what it was told to do and did: the PowerShell scripts and Win32 applications it received from the tenant, run as SYSTEM, their outcome, the policies applied, the device's registration — ATT&CK T1098.005 (device registration) and the use of the management channel itself to run code on every managed machine. The tenant's audit log is in the cloud; this is the machine's side. The MDM enrolment's own events are in the event logs (DeviceManagement-Enterprise-Diagnostics-Provider), converted there.

WHERE. ProgramData\Microsoft\IntuneManagementExtension\Logs\*.log (IntuneManagementExtension.log, AgentExecutor.log, their rotations -<date>.log…), present only where the extension was installed.

THE FORMAT, CMTrace's: each message is <![LOG[the message, possibly on several lines]LOG]!><time="15:01:02.1234567" date="10-24-2026" component="IntuneManagementExtension" context="" type="1" thread="12" file=""> the time in the machine's LOCAL time, month first in the date: converted with its time zone (suspectLocalToUtc), as every local date of WAC — or with the bias some CMTrace writers put after the time ("+300"), exact.
