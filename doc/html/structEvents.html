◆ seen

std::unordered_set<uint64_t>* Events::seen = nullptr

The events met, by the 64-bit FNV-1a digest of their key (channel, record number, creation time), when set: the volume's conversion fills it, a shadow copy's reads it. A digest rather than the key: a machine holds up to a million events; on 64 bits two of them collide with a probability below one in ten million.

◆ sink

JsonArrayWriter* Events::sink = nullptr

A shadow copy's logs (main.cpp, convertShadowCopies): only the events seen does not hold yet are written, into this writer instead of events.json, with tags added to each — the events the volume no longer holds, each once.
