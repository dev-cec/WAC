Detailed Description

The messages of a PST or OST file: folders, messages, recipients, attachments, bodies — the messaging layer on pst_file.h.

A message is a node of type 4 whose parent is a folder (type 2): the node B-tree gives them all, with no need for the folders' contents tables. Its properties are its property context; its recipients and its attachments are table contexts among its subnodes (0x692, 0x671), each attachment a property context of its own subnode. The folder path is built from the folders' display names up to the root folder (0x122).

Checked against pypff (libpff), message by message, on the test corpus: pst_test.
