Detailed Description

The machine's and its users' registration with Microsoft Entra ID (backlog B-052).

WHAT THE ARTEFACT PROVES. A machine joined to Entra ID (formerly Azure AD), or a work account added by a user ("registered" device), keeps the tenant, the account and the device's certificate thumbprint: to which organisation the machine answers, which account opened it to the cloud — ATT&CK T1098.005 (device registration), the local side of the tenant's sign-in and audit logs, which are in the cloud.

WHERE, in the copied hives:

  • SYSTEM Control\CloudDomainJoin\JoinInfo\<thumbprint> (TenantId, UserEmail, IdpDomain…) and …\TenantInfo\<tenant> (DisplayName, the MDM enrolment URLs);
  • each user's NTUSER.DAT Software\Microsoft\Windows NT\CurrentVersion\ WorkplaceJoin\JoinInfo and …\TenantInfo, for a registered device. Every value is given as stored.

The token caches the accounts leave (TokenBroker, the AAD broker plug-in) are taken raw by the collection, encrypted by DPAPI as Windows keeps them, never decrypted by WAC.
