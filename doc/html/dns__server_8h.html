Detailed Description

The DNS Server role: configuration, zones, records and debug log.

WHAT THE ARTEFACT PROVES. A DNS server answers for a whole network. A record added or changed redirects its clients (ATT&CK T1584.002, T1565); the value ServerLevelPluginDll makes the service load a DLL as SYSTEM, the known way from the DnsAdmins group to the domain; forwarders send its queries elsewhere; the debug log, when it is on, names who asked for what.

WHERE, measured on Server 2022:

  • SYSTEM Services\DNS\Parameters: the server's settings, every value kept;
  • SOFTWARE Microsoft\Windows NT\CurrentVersion\DNS Server\Zones\<zone>: a zone kept in a file, its DatabaseFile relative to System32\dns;
  • System32\dns\*.dns (and backup): zones as master files, RFC 1035 text;
  • System32\dns\dns.log, or LogFilePath: the debug log, off by default. A zone integrated with Active Directory is in the directory, not in these files: its objects are in active_directory_objects.json, its records not decoded.

THE DEBUG LOG'S DATES are written in the language of the machine's account ("04/11/2026 09:04:04" on a French one, a 12-hour clock on an English one), with no field to say which: they are given as stored, never converted.
