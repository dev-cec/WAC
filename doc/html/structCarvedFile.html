Detailed Description

LEVEL 3 — CARVING (carving.h). The free clusters level 1 did not give as a file's content hold what is left of files whose record is gone, or says nothing true any more: each is looked at for the start of a PE, a ZIP or a PDF, cut at the end its structure gives. A file is carved only if every cluster up to that end is free, unclaimed and read so before and after — contiguous: a file NTFS fragmented is not found, never cut wrong.
