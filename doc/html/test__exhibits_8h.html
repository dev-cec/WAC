Detailed Description

Test support: a data file placed as the collection places an exhibit — in the exhibit store and in its working copy — then registered in the manifest.

WHY. The conversion reads every exhibit in the WORKING copy, never in the exhibit store (B-040): an exhibit registered with a path outside the store has no working copy, and a reader finds nothing. mft_test and usn_journal_test registered their fixtures where mft_fixtures.sh wrote them, and failed since the working copy is found by the store's folder only (2026-10-22). Used by the test harnesses only: never compiled into WAC.
