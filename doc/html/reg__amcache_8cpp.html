◆ mergeInventorySources()

void mergeInventorySources ( std::vector< AmcacheEntry > & entries)

One object per entry, when the hive and an inventory database both hold it (B-081). Measured on Windows 11 26300: 386 executables are in both, the hive keeping only ProgramId and the SHA-1, the database everything else; written twice, an executable read as two objects in WAE. An entry of the hive is merged into the database's of the same table and KeyName: the hive's key time and its values the database has not join it. When a value both hold differs, nothing is merged: two sources that disagree are both given, never one chosen silently.

Parameters
entriesevery entry, the hive's and the databases'; merged in place

Reads every inventory table of one database (B-081). WHY. From Windows 11 26300 (measured 2026-11-14), the inventory leaves Amcache.hve for SQLite databases beside it, one per table (InventoryApplication.db, InventoryApplicationShortcut.db, InventoryDevicePnp.db…): the hive keeps InventoryApplicationFile, the programs, shortcuts, devices and drivers are no longer in it.
