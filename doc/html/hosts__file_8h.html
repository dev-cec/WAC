Detailed Description

The hosts file: \\Windows\\System32\\drivers\\etc\\hosts.

WHAT THE ARTEFACT PROVES. Every name listed there is resolved to its address before any DNS query. An intruder uses it to divert a site (a bank, an update server) or to cut a security product off from its console: 127.0.0.1 update.vendor.com. An untouched Windows lists no name; each entry is therefore worth a look, and the file's modification date says when the last one was added.
