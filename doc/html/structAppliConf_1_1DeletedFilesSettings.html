Detailed Description

The options of the deleted files' recovery (wac.yml, artefacts: → deleted_files:, a section where the other artefacts have a switch; its enabled is artefacts.deletedFiles). A missing option keeps its default.

Folders never read, as paths on each volume ("\\Windows\\WinSxS"): what the system deletes by the thousand, and no intruder's file. Not $Extend as a whole: Windows 10 and later move a file deleted while still open to $Extend\$Deleted, its record named there once freed — measured on Windows 11, every witness of the harness.

◆ level

int AppliConf::DeletedFilesSettings::level = 2

How deep the recovery goes, each level including the ones below: 1, the content of the deleted records of the $MFT; 2, the names the slack of the directory indexes keeps; 3, the files carved from the free clusters — the whole free space read, for as long as it takes: asked for knowingly, never the default.
