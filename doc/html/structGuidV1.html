Detailed Description

What a version-1 GUID (RFC 4122, time-based) carries: the instant it was made and the hardware address of the machine that made it. The link tracking service makes such GUIDs (DROID) when it first tracks a file: the instant is that of the tracking's birth, UTC, and the address that of the machine — the one where the file was then.
