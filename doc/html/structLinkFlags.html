Detailed Description

The LinkFlags structure defines bits that specify which shell link structures are present in the file format after the ShellLinkHeader structure. Documentation: https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-shllink/ae350202-3ba9-4790-9e9e-98935f4ee5af
