Detailed Description

Checks the decoders of the small file artefacts on inputs whose result is known: PowerShell history, setupapi.dev.log, recycle bin $I, hosts, Report.wer, Defender's MPLog, DetectionHistory and quarantine, Zone.Identifier, and the registry values of the second lot (TrustRecords, firewall rules, certificate Blob), the NTFS security descriptors of $Secure:$SDS, the NTFS boot sector and change journal header, and the volume serial of a shortcut, the DPAPI master key header and Preferred, the paths of User Shell Folders, and the reading of an SQLite database on a private copy, its write-ahead log replayed, a Chromium History and Firefox's places and form history.

Usage (runs under wine): file_artefacts_test.exe — every check; file_artefacts_test.exe –bmc <bcache22.bmc> [folder] — the tiles WAC decodes in a bitmap cache of the test VM, for bmc-tools to be confronted with, and written as images in the folder if one is given.

WHY THIS TEST. These formats are text or a few bytes, and a decoder that misses a case still gives valid JSON: a multi-line command cut in two, a section without its end, a $I path read past the file. Each case is written here from the format's description, with what must come out, and the hostile ones — a $I truncated, a length that lies — must be refused or bounded, never read beyond the bytes given.
