Detailed Description

PowerShell profiles: the scripts PowerShell runs at each start, for every user or for one (powershell_profiles.json).

WHY. A profile runs, unseen, each time PowerShell starts — a persistence that goes through neither the registry, nor a task, nor a service. An intruder writes one line there; the defender looks at Run keys.

WHERE. For every user, in PowerShell's own folder ($PSHOME): Windows PowerShell 1 to 5.1 in System32\WindowsPowerShell\v1.0 — and in SysWOW64's on a 64-bit Windows, the 32-bit PowerShell having its own —, PowerShell 6 and 7 in Program Files\PowerShell<version> (and Program Files (x86)). For one user, in their documents: WindowsPowerShell for Windows PowerShell, PowerShell for 6 and 7 — the documents where User Shell Folders puts them (Personal: OneDrive, another disk) as well as the profile's default ones. Windows XP and Vista run PowerShell only once installed (absent by default): looked for on every version.

WHICH FILES. profile.ps1 (every host) and <host>_profile.ps1: Microsoft.PowerShell (the console), Microsoft.PowerShellISE, Microsoft.VSCode — every name ending in "profile.ps1" in those folders.
