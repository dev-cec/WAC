Detailed Description

THE CLUSTERS TAKEN AND GIVEN BACK SINCE. $Bitmap says what is free now, not what was written since the deletion: a cluster another file took after it, then freed when that file was deleted in turn, reads free and holds the other file's bytes. Measured on Windows 11: a deleted witness declared Recovered whose first 128 KiB held a file written after it. Every deleted record of the $MFT copy says which clusters its file held, and when (the latest date it carries): a cluster a LATER deleted record claims is no longer the earlier file's. A file whose record was reused since leaves no runs: what it overwrote cannot be seen this way.
