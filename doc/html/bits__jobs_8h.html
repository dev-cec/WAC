Detailed Description

Background Intelligent Transfer Service jobs: \ProgramData\Microsoft\Network\Downloader\qmgr.db (bits_jobs.json).

WHAT IT PROVES. A BITS job downloads (or uploads) files in the background, surviving reboots, as SYSTEM or a user; its "notification command line" runs a program when the transfer ends or fails. Intruders use it to fetch a payload through a proxy-friendly Windows service, and as a persistence: a job that fails again and again runs its command each time. The source URL, the destination, the command and the owner are here.

THE FORMAT. Since Windows 10, qmgr.db is an ESE database (ese_database.h): table Jobs (Id, Blob), table Files (Id, Blob). The blobs are BITS's own serialisation, undocumented, described by FireEye (BitsParser, bits_parser) and checked on a witness job of the test VM against Get-BitsTransfer: after a 16-byte header, a job gives its type, priority, state, identifier, then UTF-16 strings each preceded by its length in characters — name, description, notification program and arguments, owner SID —, its notification flags; a delimited section lists its files' identifiers; then error counts, retry delay, timeout and dates. A file gives its destination, source, temporary file, sizes, drive and volume. The whole blob is also given in hexadecimal: beyond these fields, BITS 10 keeps more (the path of the program that created the job) at places not described.

BEFORE WINDOWS 10, qmgr0.dat and qmgr1.dat, which BITS writes in turn: a header, the jobs each framed by a delimiter of its version of BITS, the same job layout without the blob's header, its files written in it after their count — each followed by a trailer not described —, then the same metadata (bits_parser, ANSSI; measured on the witness job of the Windows 8.1 VM). Each job names the queue file it was read in: the older one may hold an earlier state of the same job.

A job is written to qmgr.db when created and when a file is added; BITS changes made since may be only in the service's logs (edb*.log), collected alongside.
