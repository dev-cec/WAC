Detailed Description

The artefacts to collect, one switch each (wac.yml, section artefacts:), all on by default: a key missing from the file is on. No artefact is collected without its key. The hives, the event logs and the $MFT are not artefacts but DEPENDENCIES, copied when an artefact asked for reads them (needsUserHives, rdp_server and the logs…).

Whether an artefact asked for reads the event logs: they are a dependency of events and of rdp_server, which finds the incoming connections in them.

Returns
true if one of them is switched on

◆ needsUserHives()

bool AppliConf::CollectedArtefacts::needsUserHives ( ) const
inline

Whether an artefact asked for reads the users' hives (ntuser.dat, usrClass.dat): they are a dependency, copied then. They used to be copied only with the former registry key — typed_paths alone gave an empty typed_paths.json, read as "nothing typed". A new artefact read in a user's hive is added here.

Returns
true if one of them is switched on
