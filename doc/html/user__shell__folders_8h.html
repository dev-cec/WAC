Detailed Description

Each user's shell folders (User Shell Folders): where the desktop, the documents, the downloads really are.

WHAT THE ARTEFACT PROVES. Explorer finds a user's desktop, documents, downloads and AppData through Software\\Microsoft\\Windows\\CurrentVersion\\ Explorer\\User Shell Folders of the user's NTUSER.DAT, not at a fixed place. OneDrive moves the desktop and the documents into OneDrive\\, a company redirects them to a share, a user puts them on D:. The key traces no activity, but it says WHERE to look for the user's files — and a desktop quietly redirected to a share is itself a trace; the key's last write dates the change.

WAC FOLLOWS IT. The shortcuts of a desktop redirected to a local folder are collected there too (shortcuts.json), not only at <profile>\\Desktop. A folder on a share cannot be read raw: it is listed, not followed.
