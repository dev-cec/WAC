Detailed Description

Windows Error Reporting: the Report.wer files of the machine and of each profile.

WHAT THE ARTEFACT PROVES. When a program crashes or hangs, Windows writes a report under WER\\ReportArchive (sent) or WER\\ReportQueue (waiting), in \\ProgramData\\Microsoft\\Windows\\ for the machine and in AppData\\Local\\Microsoft\\Windows\\ for a user. Each names the program, its path, its version, the module at fault and the instant. Malware that crashes — an injection gone wrong, a tool run on the wrong system — leaves its path and the time there, often when nothing else kept it.

THE FORMAT. UTF-16LE text, one Key=Value per line. The keys used here: EventType, EventTime (a FILETIME written in decimal, UTC), ReportType, FriendlyEventName, AppName, AppPath, NsAppName, OriginalFilename, ReportIdentifier, and the problem signature Sig[n].Name / Sig[n].Value (application, version, faulting module, offset…). Every Key=Value is also kept, in order, as a Name/Value pair of Values, so that nothing the report says is lost.
