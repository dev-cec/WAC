Detailed Description

Registry artefacts of the second lot: Office trusted documents, Explorer's typed paths and searches, root certificates, Internet proxy settings, firewall rules.

Each is a small artefact of its own file, read in the copied hives; they share this header because each is a few dozen lines, and share its structure: one struct per element with toJson(), one class with getData(), toJson(), clear().

WHAT THEY PROVE.

  • Office TrustRecords: a document whose user clicked "Enable content" — with 0x7FFFFFFF at its end, "Enable macros" —, and when. The door of most macro infections.
  • TypedPaths: the paths typed in Explorer's address bar (a share, a USB key's folder).
  • WordWheelQuery: the terms searched in Explorer.
  • Root certificates: a root added to a store makes Windows trust whatever it signs — interception of TLS, signed malware. The SHA-1 of each certificate is checked against its key's name, the thumbprint Windows looks it up by.
  • Internet Settings: a proxy set for a user (traffic diverted), an automatic configuration script (a PAC served by an intruder).
  • Firewall rules: a port opened, a program allowed, by whom — every rule of the policy, Windows' own included.
