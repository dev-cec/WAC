std::vector< MovedEventLog > movedEventLogFiles ( )

The log files the registry places outside winevt\Logs (and, before Vista, outside System32\config): each file once, case ignored. Needs conf.Software and conf.CurrentControlSet open (either missing: its logs are not listed).

Returns
the logs, in the registry's order
