Detailed Description

Reading a whole file, bounded: the one function every decoder uses.

Header-only and without WAC's other headers, so that the programs built from a few sources (raw_hive_test) and the modules that do not include tools.h use it too.

A file's bytes, whole, in one read at its size — THE reading of a whole file (B-044): each decoder used to have its own, a byte-wise stream iterator for most, several without any bound on the size. BOUNDED. A file of the examined machine is hostile: its size is checked against maximum, named by each caller after what its format holds, before any allocation.
