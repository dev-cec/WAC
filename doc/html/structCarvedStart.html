uint64_t CarvedStart::needed = 0

When size is 0: the bytes from the start carvedEnd needs at least — a PE's COFF symbol table and the length of its string table (MinGW leaves them after the sections); 0 for a ZIP or a PDF, whose end is looked for as far as the bytes go.

◆ size

uint64_t CarvedStart::size = 0

The file's size, when the bytes given suffice to tell it (a PE's headers, without a COFF symbol table); 0 when the end must be found in what follows (carvedEnd).
