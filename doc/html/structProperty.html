◆ typeNotDecoded

bool Property::typeNotDecoded = false

True if the value's type could not be decoded.

The size of a Property is not declared: it is DEDUCED from the progress of the decoding. An unknown type therefore leaves the position where it was, and the next property would be read in the wrong place — producing properties that look normal and are wrong. The loops that chain properties stop on that flag: a truncated and reported list is better than a complete and invented one.
