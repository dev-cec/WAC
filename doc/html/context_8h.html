Detailed Description

The linking context of a record (Context): what the record attests, of which object, who acted, how, and where WAC read it — backlog B-079, schema validated in B-078 (2026-11-14).

WHY. WAE opens the file of any object (an executable, a script, a document, an account, a software, a device…): everything that relates to it, across artefacts. The same object is named differently by each artefact (\Device\HarddiskVolume3\… in BAM, C:\… in Prefetch, a folder id in UserAssist, a command line in a Run key); WAC alone knows the machine — its volumes, its profiles —, so WAC writes, in every record, the objects it names in one form. WAE only relates.

WHAT IT HOLDS: identities only. The instants stay in the record's own fields, which WAE's timeline already reads.

ONE WRITER for every collector, as Json::add is: a member without value is not emitted (shared rule n° 1), a Context with nothing is not emitted.
