Detailed Description

The DHCP Server role: configuration, scopes, leases and audit log.

WHAT THE ARTEFACT PROVES. The audit log and the lease database say which machine held which address when: what ties an address seen in another log to a device (its hardware address, its name). A scope's options set the gateway and the DNS servers of a network. The value CalloutDlls makes the service load DLLs as its own account.

WHERE, measured on Server 2022:

  • SYSTEM Services\DHCPServer\Parameters: settings, DatabasePath, DhcpLogFilePath, DhcpV6LogFilePath, CalloutDlls;
  • dhcp.mdb in DatabasePath, ESE, with its logs: ClientTable (IPv4 leases), LeaseTable (IPv6), DbcfgTable (scopes and class definitions), ConfigTable6;
  • DhcpSrvLog-<day>.log, DhcpV6SrvLog-<day>.log: the audit log, one file per day of the week, overwritten after seven days.

THE AUDIT LOG. Comma-separated, its header in the machine's language: columns are known by their position, not by that header. The date is MM/dd/yy (measured on a French server, "11/04/26" on 4 November), local time: converted with the examined machine's time zone.

ClientTable's HardwareAddress starts with the subnet (4 bytes, low byte first) and a hardware type byte: measured, 00 02 00 C0 01 for 192.0.2.0 before the client id.
