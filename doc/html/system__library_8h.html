Detailed Description

A Windows library loaded at run time, from System32 only, and its functions resolved — for the libraries WAC must not import.

WinHTTP (–update-trust, http_client.cpp), iphlpapi (the network state, network.cpp) and esent.dll (the replay of ESE logs, ese_recovery.cpp) are each needed in one mode only: imported, they would be loaded at every start of WAC.exe on the examined machine, and stand in its import table, which the harmlessness file describes. Loaded from System32 only: never a DLL of the current folder or of the collection medium.
