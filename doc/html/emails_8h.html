Detailed Description

The mail of every profile: Outlook's PST and OST files, their messages and attachments (emails.json).

WHAT THE ARTEFACT PROVES. What a user sent and received, to whom, when, and what was attached: a document leaving by mail, a phishing message and its attachment, an intruder's exchanges from the account.

THE SOURCES. Outlook keeps its mailboxes as PST files (archives, POP accounts: Documents\\Outlook Files) and OST files (the offline copy of an Exchange or Microsoft 365 mailbox: AppData\\Local\\Microsoft\\Outlook), read by pst_file.h and pst_messages.h. The files Outlook opened from a message are in INetCache\\Content.Outlook, the new Outlook's (olk.exe) local data in AppData\\Local\\Microsoft\\Olk: collected as they are, not decoded — no sample of the latter to check a decoder on. Thunderbird keeps each folder as an mbox file in its profiles (AppData\\Roaming\\Thunderbird\\Profiles), read by mbox_mail.h; the profiles are collected whole — the address book and the settings with the mail.

THE OUTPUT. A record per mailbox file — its kind, version, the number of messages read and of those that could not be — and a record per message: its folder, class, subject, sender, recipients, times, Internet message identifier and transport headers. Each body (text, HTML) and each attachment is written next to the JSON, under emails\\<SID>\\<file>\\<message>\\, and the JSON gives its SHA-256. The attachment's own name, chosen by whoever sent it, is never a path: the file is named by its rank, with the name's extension when it is a plain one; the name itself is in the JSON.
